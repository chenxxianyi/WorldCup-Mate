# WorldCup Mate 首发阵容提醒与赛后补看摘要前端开发方案

## 1. 目标

为个人自用世界杯助手补齐两个体验：

1. 首发阵容提醒：收到站内通知后，可以一键进入比赛详情页查看首发和阵型。
2. 赛后补看摘要：比赛结束后，在比赛详情页查看 AI 生成的赛后补看摘要。

前端重点是：

- 通知中心支持不同类型通知和跳转。
- 比赛详情页展示赛后摘要卡片。
- 不破坏现有比赛详情、首发阵容、AI 看点功能。

## 2. 依赖后端能力

后端需要提供：

### 通知字段

```ts
interface NotificationItem {
  id: number
  title: string
  content: string
  type: 'reminder' | 'lineup' | 'post_match_summary' | string
  target_type?: 'match' | string
  target_id?: number
  is_read: boolean
  created_at: string
}
```

### 赛后摘要接口

```http
GET /api/matches/:id/post-match-summary
POST /api/matches/:id/post-match-summary/generate
```

### 3.3 通知点击行为

当前点击通知只标记已读。需要改为：

1. 如果未读，先标记已读。
2. 如果 `target_type === 'match' && target_id`，跳转比赛详情页。

实现建议：

```ts
async function openNotification(item: NotificationItem) {
  if (!item.is_read) {
    await notification.markRead(item.id)
  }

  if (item.target_type === 'match' && item.target_id) {
    router.push(`/matches/${item.target_id}`)
  }
}
```

`NotificationList.vue` 需要引入：

```ts
import { useRouter } from 'vue-router'
```

### 3.4 通知类型展示

新增类型文案方法：

```ts
function typeText(type: string) {
  if (type === 'lineup') return '首发'
  if (type === 'post_match_summary') return '赛后'
  if (type === 'reminder') return '提醒'
  return '通知'
}
```

UI 建议：

- 在标题前或标题右侧展示小标签。
- 不使用 emoji，使用文字标签即可。
- 未读通知保留现有红点。

示例结构：

```vue
<span class="notice-type">{{ typeText(item.type) }}</span>
<b>{{ item.title }}</b>
```

样式：

### 3.5 刷新策略

## 4. 赛后补看摘要 API

### 4.1 新增 API 文件

建议新增：

```text
frontend/src/api/postMatchSummary.ts
```

内容：

```ts
import request from './request'
import type { PostMatchSummary } from '@/types/postMatchSummary'

export function apiGetPostMatchSummary(matchId: number) {
  return request.get(`/matches/${matchId}/post-match-summary`) as Promise<PostMatchSummary | any>
}

export function apiGeneratePostMatchSummary(matchId: number, forceRefresh = false) {
  return request.post(`/matches/${matchId}/post-match-summary/generate`, {
    force_refresh: forceRefresh,
  }) as Promise<PostMatchSummary>
}
```

也可以放进现有 `frontend/src/api/ai.ts`，但独立文件更清晰。

### 4.2 新增类型

新增：

```text
frontend/src/types/postMatchSummary.ts
```

内容：

```ts
export interface PostMatchSummary {
  summary: string
  score_line: string
  key_takeaways: string[]
  qualification_impact: string
  worth_watching: string
  spoiler_level: string
  data_note: string
  generated_at: string
}

export function hasPostMatchSummary(value: any): value is PostMatchSummary {
  return Boolean(value?.summary || value?.score_line)
}
```

## 5. 赛后补看摘要卡片

### 5.1 新增组件

新增：

```text
frontend/src/components/ai/PostMatchSummaryCard.vue
```

Props：

```ts
const props = defineProps<{
  summary: PostMatchSummary | null
  loading?: boolean
  error?: string
  canGenerate?: boolean
}>()
```

Emits：

```ts
const emit = defineEmits<{
  (e: 'generate'): void
  (e: 'refresh'): void
}>()
```

### 5.2 展示状态

状态分为：

1. 比赛未结束：不显示组件，或显示不可用空态。
2. 比赛已结束，无摘要：显示“生成赛后补看摘要”按钮。
3. 摘要生成中：显示加载态。
4. 摘要生成失败：显示错误和重试按钮。
5. 有摘要：展示摘要内容。

### 5.3 UI 内容

卡片内容建议：

- 标题：赛后补看摘要
- 比分：`summary.score_line`
- 摘要正文：`summary.summary`
- 关键要点：`summary.key_takeaways`
- 是否值得补看：`summary.worth_watching`
- 出线影响：`summary.qualification_impact`
- 数据说明：`summary.data_note`

移动端设计：

- 使用单张 `card`。
- 内容纵向排列。
- 要点列表不要太密，每条 1-2 行。
- 按钮放在卡片底部或右上角。

### 5.4 组件示例结构

```vue
<template>
  <section class="card post-summary-card">
    <div class="summary-head">
      <div>
        <span>AI</span>
        <h2>赛后补看摘要</h2>
      </div>
      <button v-if="summary" class="text-action" @click="emit('refresh')">刷新</button>
    </div>

    <div v-if="loading" class="summary-state">正在生成摘要...</div>
    <div v-else-if="error" class="summary-state error">{{ error }}</div>
    <div v-else-if="!summary" class="summary-empty">
      <p>比赛结束后可生成补看摘要。</p>
      <button class="pill-btn primary" :disabled="!canGenerate" @click="emit('generate')">
        生成赛后补看摘要
      </button>
    </div>
    <div v-else class="summary-body">
      <strong>{{ summary.score_line }}</strong>
      <p>{{ summary.summary }}</p>
      <ul>
        <li v-for="item in summary.key_takeaways" :key="item">{{ item }}</li>
      </ul>
      <div class="summary-note">{{ summary.worth_watching }}</div>
      <small>{{ summary.data_note }}</small>
    </div>
  </section>
</template>
```

## 6. 比赛详情页接入

### 6.1 修改文件

```text
frontend/src/pages/user/MatchDetailPage.vue
```

新增状态：

```ts
const postSummary = ref<PostMatchSummary | null>(null)
const postSummaryLoading = ref(false)
const postSummaryError = ref('')
```

新增计算：

```ts
const canGeneratePostSummary = computed(() =>
  match.value?.status === 'finished' &&
  match.value.home_score != null &&
  match.value.away_score != null
)
```

如果当前页面没有引入 `computed`，需要从 Vue 增加。

### 6.2 加载已有摘要

在 `loadMatch()` 成功后：

```ts
loadPostMatchSummary(id)
```

实现：

```ts
async function loadPostMatchSummary(matchId: number) {
  postSummary.value = null
  postSummaryError.value = ''

  try {
    const res = await apiGetPostMatchSummary(matchId)
    if (hasPostMatchSummary(res)) {
      postSummary.value = res
    }
  } catch {
    postSummary.value = null
  }
}
```

### 6.3 手动生成摘要

```ts
async function generatePostSummary(forceRefresh = false) {
  if (!match.value || !canGeneratePostSummary.value) return
  postSummaryLoading.value = true
  postSummaryError.value = ''

  try {
    postSummary.value = await apiGeneratePostMatchSummary(match.value.id, forceRefresh)
  } catch {
    postSummaryError.value = '赛后摘要生成失败'
  } finally {
    postSummaryLoading.value = false
  }
}
```

### 6.4 页面放置位置

建议放在比分英雄卡片之后、赛前 AI 看点之前：

```vue
<PostMatchSummaryCard
  v-if="match.status === 'finished'"
  :summary="postSummary"
  :loading="postSummaryLoading"
  :error="postSummaryError"
  :can-generate="canGeneratePostSummary"
  @generate="generatePostSummary(false)"
  @refresh="generatePostSummary(true)"
/>
```

原因：

- 比赛结束后，用户最先想看结果和摘要。
- 首发阵容和小组积分仍保留在后面。

## 7. 首发阵容提醒前端体验

首发阵容提醒本身主要由后端触发。前端需要做到：

1. 通知中心展示 `lineup` 类型。
2. 点击通知进入比赛详情页。
3. 比赛详情页已有 `MatchLineups`，无需新增大逻辑。
4. 进入比赛详情页时正常调用 `apiGetMatchLineups`，显示最新阵容。

可选增强：

- 在 MatchCard 上对已公布首发的比赛显示 `首发` 小标签。
- 在赛程页筛选中增加 `首发已公布`。

第一版不建议做筛选，先保证通知跳转即可。

## 8. 免剧透模式预留

如果后续实现免剧透模式，前端需要：

### 通知中心

- `post_match_summary` 通知标题不展示比分。
- 通知内容保持中性。

### 比赛详情页

- `PostMatchSummaryCard` 默认折叠。
- 显示按钮：`显示赛后摘要`。
- 用户点击后再展示比分和摘要正文。

第一版可以只在组件内预留 prop：

```ts
spoilerSafe?: boolean
```

暂不接入全局设置。

## 10. 错误处理

### 摘要未生成

展示：

```text
比赛结束后可生成补看摘要
```

### 比赛未结束

不显示摘要卡片，或按钮 disabled。

### AI 失败

展示：

```text
赛后摘要生成失败，请稍后重试
```

### 后端返回数据不足

展示后端 `data_note`，例如：

```text
当前摘要仅基于比分、阵容和积分信息生成。
```

## 11. 验收标准

### 通知中心

- `lineup` 通知能正常展示。
- `post_match_summary` 通知能正常展示。
- 点击 match 类型通知能跳转比赛详情页。
- 点击未读通知后未读数减少。

### 比赛详情页

- 未结束比赛不展示赛后摘要卡片。
- finished 比赛展示摘要入口。
- 点击生成按钮后展示 loading。
- 生成成功后展示摘要、比分、要点、补看建议。
- 刷新页面后能读取已有摘要。
- 点击刷新能重新生成摘要。

### 构建

- `npm run build` 通过。

## 12. 推荐开发顺序

1. 扩展 `NotificationItem` 类型。
2. 通知列表支持类型标签和 match 跳转。
3. 新增赛后摘要类型和 API。
4. 新增 `PostMatchSummaryCard.vue`。
5. 比赛详情页接入摘要卡片。
6. 联调首发通知跳转。
7. 联调赛后摘要生成。
