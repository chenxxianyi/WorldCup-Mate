# WorldCup Mate 前端卡片化样式优化方案

## 1. 背景

当前 WorldCup Mate 的移动端界面已经具备比较完整的世界杯赛事氛围：玻璃导航、倒计时计分牌、比赛卡片、进度卡片、关注模块、底部导航等组件都有独立设计。但由于页面中大量模块都采用了完整卡片样式，导致同屏出现过多边框、圆角、白底和容器阴影，视觉层级变得碎片化。

本方案目标不是删除信息，而是减少不必要的卡片容器，把界面从“多个盒子堆叠”优化为“赛事直播面板 + 比赛票据 + 信息流”的结构。

## 2. 当前问题

### 2.1 卡片数量过多

首页首屏目前包含多个强容器：

- 顶部玻璃导航栏
- 下一场比赛倒计时卡片
- 小组赛阶段进度卡片
- 我的关注 section
- 关注比赛卡片
- 关注球队卡片
- 底部导航卡片

这些元素都使用了较完整的容器边界，导致视觉上每一块都在争夺注意力。

### 2.2 层级表达方式重复

当前很多模块都依赖以下方式表达层级：

- 白底背景
- 圆角边框
- 完整卡片包围
- 内部 padding
- 浅阴影或 hover shadow

当所有模块都使用同一套层级手段时，用户难以快速判断哪些内容更重要。

### 2.3 信息流连续性不足

世界杯助手类产品更适合“赛事信息流”和“直播面板”风格。过多卡片会让页面像管理后台或组件陈列，而不是一个连续的观赛助手。

## 3. 优化目标

1. 保留世界杯赛事氛围。
2. 降低普通内容的卡片感。
3. 只让关键内容使用强视觉容器。
4. 通过分区、间距、时间轴、列表行、票据条替代部分卡片。
5. 建立统一的组件层级规则，减少后续页面继续堆卡片。

## 4. 新视觉结构

建议将页面内容分为三层。

### 4.1 主舞台

用于页面最重要的信息，允许保留强视觉设计。

适用内容：

- 下一场比赛倒计时
- 焦点比赛
- AI 推荐比赛
- 比赛详情页主比分
- 直播中的关键比赛

推荐样式：

- 深色赛事大屏
- 计分牌
- 全宽视觉面板
- 少量渐变和光效

限制：

- 同屏尽量只出现一个主舞台。
- 主舞台可以强，但周围内容要轻。

### 4.2 分区

用于组织页面模块，不一定需要卡片容器。

适用内容：

- 我的关注
- 今日赛程
- 比赛时间线
- 小组积分
- 关注球队
- AI 看球助手入口

推荐样式：

- section 标题
- 轻量背景带
- 上下间距
- 局部分割线
- 左侧小色条

限制：

- 不默认使用 `.card`。
- 分区不嵌套卡片。

### 4.3 信息行

用于普通列表内容。

适用内容：

- 普通比赛
- 时间线比赛
- 关注球队
- 收藏比赛
- 提醒列表
- 积分榜条目

推荐样式：

- list row
- 时间轴节点
- 比赛票据条
- 紧凑表格行
- 图标 + 文本 + 操作按钮

限制：

- 普通信息行不使用完整卡片边框。
- 只在重要状态下增加轻背景或色条。

## 5. 组件替代方案

| 当前组件/样式 | 当前问题 | 建议替代 |
|---|---|---|
| `.card` 默认卡片 | 使用范围过宽，导致页面碎片化 | 改为弱容器或仅在关键内容使用 |
| `stage-card` | 进度信息不需要完整白卡片 | 改为赛事进度带 |
| `MatchCard` 普通比赛卡片 | 每场比赛都像重点内容 | 拆成普通比赛票据和焦点比赛卡 |
| `TimelineMatchCard` | 时间线条目仍偏卡片 | 改为真正的时间轴列表项 |
| 关注球队卡片 | 信息密度低，占用空间大 | 改为横向球队徽章列表 |
| 空状态卡片 | 空信息也占据强容器 | 改为轻量文字 + 图标 |
| 底部导航白底卡片 | 与顶部导航和内容卡片叠加 | 改成透明玻璃胶囊或无边界浮层 |

## 6. 首页优化建议

### 6.1 顶部导航

保留玻璃导航风格，但作为工具条存在，不再与内容卡片形成竞争。

建议：

- 保持轻玻璃背景。
- 图标按钮使用透明玻璃。
- 减少厚重白底。

### 6.2 下一场比赛

保留强视觉设计，这是首页主舞台。

建议：

- 继续使用深色赛事大屏。
- 倒计时使用上下翻页计分牌效果。
- 视觉强度集中在这一块。

### 6.3 小组赛阶段进度

由白色卡片改为进度带。

建议结构：

```text
小组赛阶段                         0.0%
━━━━━━━━━━━━────────────
已完成 0 场                       剩余 104 场
```

视觉建议：

- 去掉完整卡片边框。
- 进度条直接放在页面背景上。
- 只用文字权重和颜色区分状态。

### 6.4 我的关注

由卡片堆叠改为分区信息流。

建议结构：

```text
我的关注                         2 支球队

关注的比赛
[06-17] 法国 vs 塞内加尔       03:00  提醒  收藏

关注的球队
[法国] [日本]
```

视觉建议：

- `我的关注` 作为 section，不加外层卡片。
- `关注的比赛` 使用比赛票据条。
- `关注的球队` 使用横向徽章列表。

### 6.5 关注比赛

当前比赛卡片可以拆分为两种：

- `FeaturedMatchPanel`：用于热门比赛、推荐比赛。
- `MatchTicketRow`：用于普通比赛列表。

普通比赛票据建议：

- 左侧日期角标。
- 中间队伍和 VS。
- 右上角状态标签。
- 底部一条细分割线放时间、场馆和操作。
- 可以保留极轻边框，但不要像完整白卡片。

### 6.6 时间线

时间线不应每条都是卡片。

建议结构：

```text
6月17日
  03:00  法国        vs        塞内加尔
  06:00  巴西        vs        ...

6月18日
  03:00  ...
```

视觉建议：

- 左侧时间列固定宽度。
- 中间用细线或节点表达时间流。
- live 状态用红点和轻背景即可。
- finished 状态用对勾或比分高亮。

## 7. 全局样式规则

### 7.1 卡片使用规则

强卡片只用于：

- 主视觉面板
- 焦点比赛
- 详情页核心信息
- 弹窗
- 需要完整边界的输入表单

普通信息不要使用强卡片：

- 列表条目
- 时间线条目
- 队伍条目
- 进度信息
- 空状态

### 7.2 容器层级规则

建议建立三种容器 token：

```css
.surface-hero     /* 强视觉主舞台 */
.surface-section  /* 轻分区背景 */
.surface-row      /* 信息行 */
```

其中：

- `surface-hero` 可以有较强背景、圆角和光效。
- `surface-section` 只负责分区，不要明显边框。
- `surface-row` 只用分割线、浅背景或 hover 态。

### 7.3 圆角规则

建议统一：

- 主舞台：18px - 24px
- 普通容器：10px - 14px
- 列表行：0px - 8px
- 标签和按钮：999px

### 7.4 阴影规则

浅色模式：

- 默认不使用阴影。
- 仅主舞台和悬浮导航可以使用轻阴影。

暗色模式：

- 可以用微弱外发光或边框。
- 避免多个卡片都带重阴影。

### 7.5 边框规则

建议减少完整包围边框，改用：

- 顶部分割线
- 左侧状态色条
- 底部分隔线
- 时间轴竖线
- 标签角标

## 8. 分阶段实施计划

### 第一阶段：首页减卡片

目标：先解决首屏卡片过多的问题。

任务：

1. 将 `stage-card` 改为无卡片进度带。
2. 将“我的关注”外层改为普通 section。
3. 将关注球队卡片改为横向球队徽章列表。
4. 将普通关注比赛改为 `MatchTicketRow`。
5. 保留倒计时作为唯一主舞台。

预期收益：

- 首屏更清爽。
- 主视觉更突出。
- 视觉碎片感明显降低。

### 第二阶段：比赛组件分级

目标：让比赛信息按重要性选择不同组件。

任务：

1. 拆分 `MatchCard`：
   - `FeaturedMatchPanel`
   - `MatchTicketRow`
2. 赛程页默认使用 `MatchTicketRow`。
3. 首页推荐位或热门比赛使用 `FeaturedMatchPanel`。
4. 收藏/提醒列表使用更紧凑的信息行。

预期收益：

- 普通比赛不会抢焦点。
- 同一类比赛信息更统一。

### 第三阶段：时间线重构

目标：让时间线真正成为信息流。

任务：

1. 将 `TimelineMatchCard` 改为时间轴 row。
2. 日期标题改为 sticky 或分组标题。
3. live、finished、scheduled 使用状态点和局部高亮。
4. 减少每条时间线的边框和圆角。

预期收益：

- 时间顺序更直观。
- 长列表阅读效率更高。

### 第四阶段：全局 `.card` 收敛

目标：避免后续继续滥用卡片。

任务：

1. 重新定义 `.card` 的适用范围。
2. 新增 `surface-*` 工具类。
3. 逐步替换页面内不必要的 `.card`。
4. 为新组件建立示例和使用说明。

预期收益：

- 视觉系统更稳定。
- 后续开发更容易保持一致。

## 9. 推荐最终风格

推荐 WorldCup Mate 采用以下风格组合：

```text
赛事直播面板 + 比赛票据 + 时间轴列表 + 轻玻璃导航
```

这套风格的好处：

- 符合世界杯赛事产品的情绪。
- 比纯卡片式布局更有流动感。
- 信息密度更高。
- 关键内容更突出。
- 移动端阅读更轻松。

## 10. 验收标准

首页优化完成后，可以按以下标准验收：

1. 首屏除导航和倒计时外，不再出现多个强卡片。
2. 普通比赛列表不再全部使用完整白底卡片。
3. 时间线条目能一眼看出时间顺序。
4. 关注球队区域占用高度降低。
5. 页面信息层级更清楚：主舞台、分区、信息行各自明确。
6. 浅色和暗色模式都没有明显“卡片堆叠感”。
7. 触控区域仍保持至少 44px。
8. 关键文字对比度保持可读。

## 11. 建议优先级

优先做首页，因为首页最能体现产品气质，也是卡片堆叠最明显的位置。

推荐顺序：

1. 首页阶段进度带
2. 首页关注球队徽章列表
3. 首页关注比赛票据条
4. 时间线 row 化
5. 赛程页比赛列表 row 化
6. 全局 `.card` 规则收敛
